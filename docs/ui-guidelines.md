# GKLI Flex - Diretrizes Visuais

## Tom Visual

O GKLI Flex deve seguir uma interface operacional discreta, limpa e leve.

## Tipografia

- Evitar fontes grandes.
- Evitar excesso de negrito.
- Usar peso médio apenas para rótulos, títulos de painel e itens principais.
- Manter números e métricas discretos.
- Usar títulos de página claros, mas contidos.

## Cabeçalhos

- O cabeçalho superior deve identificar o módulo.
- O subtítulo deve contextualizar a rotina de forma curta.
- O cabeçalho da página deve usar um marcador pequeno, título discreto e descrição objetiva.
- Ações principais ficam à direita, como no padrão operacional do COB.

## Cores

- Classic Blue é a cor principal.
- Classic Blue deve funcionar como acento e orientação, não como área dominante.
- Evitar telas monocromáticas.
- Status devem usar cores funcionais:
  - Azul: informativo
  - Verde: concluído
  - Amarelo: atenção
  - Vermelho: bloqueio

## Layout

- Interface de trabalho, não landing page.
- Cards leves e poucos.
- Sem dashboards pesados.
- Sem números gigantes.
- Sem seções decorativas.
- Tabelas e listas devem ser escaneáveis.

## Componentes

- Usar badges para status.
- Usar botões com ícones quando houver comando claro.
- Usar estados vazios consistentes.
- Usar mensagens inline para alerta, erro e informação.

## Referência

O app deve manter a sensação operacional do `gkli-cob`, mas com identidade própria do `gkli-flex`.
