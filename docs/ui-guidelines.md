# GKLI Flex - Diretrizes Visuais

## Tom Visual

O GKLI Flex deve seguir uma interface operacional discreta, limpa e leve.

## Tipografia

- Evitar fontes grandes.
- Evitar excesso de negrito.
- Usar peso medio apenas para rotulos, titulos de painel e itens principais.
- Numeros e metricas devem ser discretos.
- Titulos de pagina devem ser claros, mas contidos.

## Cores

- Classic Blue e a cor principal.
- Classic Blue deve funcionar como acento e orientacao, nao como area dominante.
- Evitar telas monocromaticas.
- Status devem usar cores funcionais:
  - Azul: informativo
  - Verde: concluido
  - Amarelo: atencao
  - Vermelho: bloqueio

## Layout

- Interface de trabalho, nao landing page.
- Cards leves e poucos.
- Sem dashboards pesados.
- Sem numeros gigantes.
- Sem secoes decorativas.
- Tabelas e listas devem ser escaneaveis.

## Componentes

- Usar badges para status.
- Usar botoes com icones quando houver comando claro.
- Usar estados vazios consistentes.
- Usar mensagens inline para alerta/erro/informacao.

## Referencia

O app deve manter a sensacao operacional do `gkli-cob`, mas com identidade propria do `gkli-flex`.
